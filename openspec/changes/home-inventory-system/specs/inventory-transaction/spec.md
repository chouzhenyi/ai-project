## ADDED Requirements

### Requirement: 出入库操作记录

系统 SHALL 记录每次物品数量变动的完整操作轨迹。

#### Scenario: 入库操作
- **WHEN** 用户向容器内增加物品
- **THEN** 系统记录入库操作，包含物品、数量、容器、操作人、时间

#### Scenario: 出库操作
- **WHEN** 用户从容器中取出物品
- **THEN** 系统记录出库操作，必填去向字段

#### Scenario: 调拨操作
- **WHEN** 用户将物品从一个容器转移到另一个容器
- **THEN** 系统记录调拨操作，包含来源和目标容器

#### Scenario: 盘点调整
- **WHEN** 用户发现实际数量与系统不一致并调整
- **THEN** 系统记录调整操作并备注原因

### Requirement: 去向必填

系统 SHALL 在出库时强制填写物品去向。

#### Scenario: 快捷去向选择
- **WHEN** 用户出库时点击去向输入框
- **THEN** 系统展示常用去向快捷选项（在用、车上、公司、送人、扔掉、挪箱等）

#### Scenario: 自定义去向输入
- **WHEN** 用户选择自定义输入去向
- **THEN** 系统允许用户手动打字填写去向

#### Scenario: 语音输入去向
- **WHEN** 用户点击语音输入按钮
- **THEN** 系统调用 Web Speech API 识别语音填入去向

#### Scenario: 去向为空阻止出库
- **WHEN** 用户提交出库但去向字段为空
- **THEN** 系统提示"去向为必填项"并阻止提交

### Requirement: 操作历史查询

系统 SHALL 支持按物品、容器、时间范围查询操作历史。

#### Scenario: 查询物品操作历史
- **WHEN** 用户查看某物品的详情
- **THEN** 系统展示该物品的全部出入库记录

#### Scenario: 查询容器操作历史
- **WHEN** 用户查看某容器的操作历史
- **THEN** 系统展示该容器内的全部操作记录
